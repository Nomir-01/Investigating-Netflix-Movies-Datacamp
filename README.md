# Investigating Netflix Movies

An exploratory analysis of Netflix titles focused on films released during the 1990s. The notebook determines the most common movie duration for the decade and counts short action films using pandas-based filtering and visualization.

## Analysis questions

- What was the most frequent movie duration during the 1990s?
- How many action movies from the decade were shorter than 90 minutes?

## Tools

- Python
- pandas and NumPy
- Matplotlib
- Jupyter Notebook

## Repository contents

- `notebook.ipynb` — exploration, filtering, and calculations
- `netflix_data.csv` — Netflix title data
- `redpopcorn.jpg` — project cover image
- `requirements.txt` — Python dependencies

## Run locally

```bash
python -m venv .venv
python -m pip install -r requirements.txt
jupyter lab notebook.ipynb
```
